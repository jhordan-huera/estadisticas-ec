# Logos de los clubes

Las imágenes usan el escudo de cada equipo (`"usarLogos": true` en la sección `marca` de
`config/marcador.config.json`). Cada archivo se llama con la abreviatura configurada en
`config/equipos.json`: `LDU.png`, `BSC.png`, `IDV.png`…

- Formato: PNG con fondo transparente, idealmente 500×500 o más.
- Un equipo sin archivo se muestra con su marca de color (abreviatura sobre su color).
- Para volver a las marcas de color en todas las piezas: `"usarLogos": false`.
